The one-sentence core

Grove freezes a Graph Toolkit doodle into a blob of headers + payloads + pointers, then walks it from ECS by jumping on an integer Type through a source-generated switch living on your context — with all mutable graph memory in a shared per-entity GroveState map.

Runtime loop (memorize)

OnCreate:  impl = new GraphImpl<MyContext>(ref state)
OnUpdate:  execution = impl.GetExecution(ref state)
IJobChunk:
  execution.SetChunk(chunk, index)
  foreach entity:
    execution.TrySetInput(... )   // writes GroveState
    execution.Execute(e, i, blob) // Root.Execute → switch(Type)
    // or Calculate<TOut>(...) for data-only graphs

Hard rules (fail closed)

Execution graphs need exactly one root Input boundary connected to an execution node. Untyped Graph Toolkit variables are for routing/entry only — they are not baked as runtime Inputs/Outputs. Variants are bake-time strip, not per-frame if/else. Context must be partial struct with GroveStates. Node methods: static, non-generic outer type, context by ref.

Rebuild checklist

  1. Define graph type + ScriptedImporter + AuthGraph subclass.
  2. Author nodes (editor + auth + unmanaged payload + static method).
  3. Place GraphAuthoring<Auth, Component> referencing imported Auth.
  4. Implement IGraphReference component; let bake invent the system.
  5. Implement partial struct MyContext : IContext<MyContext>.
  6. System owns GraphImpl, job calls SetChunk then Execute/Calculate.
  7. Use GroveState for inputs, locals, state machines; tear down by GraphId.
