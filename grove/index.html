How Grove works — mastery path

Archify maps + short/deep voice. Hover a box for the short line; click for the deep line with real package types. Guided tour walks one map in order.

Open explore Prefer http:// (not file://) so map hover can bind. Local: python3 -m http.server 8765 from this folder.
Auth means authoring — never login. GroveAuth / GroveAuthGraph are ScriptableObject cards produced by import. They are not authentication, JWT, or security login. Runtime only consumes the baked GraphData brick.
How explore works. Short = hover (or rail hover). Deep = click the box (or click the rail row again / Go deeper). Y guided tour · M mute · 1–N switch map · Space replay. Click once on the page so the browser unlocks voice.

Study order

  1. Open explore over http://.
  2. Do lessons 01 → last with hover + click (short then deep). Use the guided tour once per map if you like.
  3. When a deep line names a type, treat it as searchable in com.bovinelabs.grove.
  4. After the path, you should be able to add a custom node and hang a graph on an entity without guessing ownership.

Glossary (read once)

Source graph
Graph Toolkit asset (e.g. .mygraph deriving GroveGraph). Editor-only.
Auth graph / Auth card
GroveAuthGraph main asset + GroveAuth* subassets from import. Authoring intermediate. Not login.
GraphData brick
Immutable BlobAssetReference<GraphData>. Runtime recipe: Root, I/O, node maps, BlobPtr ports.
GraphAuthoring
MonoBehaviour that points at an Auth graph (+ variants / instance overrides) for bake.
IGraphReference
ECS component/buffer element holding the baked blob.
IContext / GraphImpl / GraphExecution
Your partial context; system owns GraphImpl; per-update GraphExecution runs Root.
GroveState
Per-entity live backpack (inputs, locals, state keys). Not stored inside the brick.
Type int
Header field; source-gen switch picks static Execute/Calculate methods.

After the path

  • Point at each assembly and say what it owns (Editor / Authoring / Runtime).
  • Write the ISystem skeleton around GraphImpl without guessing.
  • Add a custom execution or data node without cargo-culting a fourth Auth layer.
  • Know inputs live in entity GroveState, not stack args on Root.
  • Know variants strip at bake; instance overrides patch Auth fields before Create.
