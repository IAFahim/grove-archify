How Grove works

Watch the maps in order. Each opens as an interactive Archify diagram (dark + present mode). Press ? in a map for controls, P for guided stories.

Kid version in one line: you draw a treasure map → Grove freezes it into a brick → a robot reads the brick every frame by opening doors with numbers.
